# alex-architect

Личный плагин Александра для Claude Code. Стратег-оркестратор + рабочие скиллы:
контент его голосом, карты для клиентов, презентации, анализ сайтов и кода.

## Установка (один раз, работает во всех чатах)
    claude plugin marketplace add <путь-или-github-репо>
    claude plugin install architect@alex-architect

После этого скиллы включаются автоматически под задачу.
