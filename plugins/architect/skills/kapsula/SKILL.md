# Капсула: полная картина за копейки

Правило Александра от 17.10.2026: запуск и чтение любого чата не должны съедать больше 5% дневного лимита.

## Откуда на самом деле уходит лимит

1. **Длина самого чата.** Каждый мой ответ заново обрабатывает всю историю чата. Чат на сотни сообщений
   дорог в каждом ответе, и это не лечится ничем, кроме нового чата.
2. **Субагенты.** Один агент — около 140 тысяч токенов только на запуск (замерено 14.10.2026).
3. **Большие выводы инструментов.** Полный файл на 350 КБ, длинные страницы Notion, широкие поиски.
4. **Перечитывание того, что уже выжато в память.**

## Старт любого чата — не больше двух чтений

1. Профиль и предпочтения уже загружены сами — их не читать.
2. Прочитать **одну** капсулу: файл памяти `/areas/kapsula.md` (до 2 КБ).
3. Всё остальное — только по прямой необходимости текущей задачи и точечно.
   - Страницы Notion не открывать целиком «для контекста»: ссылки в капсуле, открывать только ту, с которой работаем.
   - Скиллы читать только тот, что нужен под задачу.

## Перед каждым дорогим действием

| Действие | Правило |
|---|---|
| Субагент | Только с его «да». Сначала сказать цену: «N агентов ≈ N × 140 тыс. токенов» |
| Большой файл | Сначала размер (`wc -c`), читать кусками: `head -c`, `grep`, нужный раздел |
| Notion | Создавать и дописывать — можно. Целиком читать длинную страницу — только если без неё нельзя |
| Веб-поиск | Один точный запрос вместо пяти широких |
| Вывод команды | Всегда обрезать: `head`, `tail`, `grep`. Никогда не печатать файлы целиком |

## Когда предложить новый чат

Одной строкой, сам, не дожидаясь, если выполнено одно из условий:
- в чате больше ~40 ответов;
- в чате был большой вывод (агенты, длинные документы, сотни строк кода);
- тема сменилась: новая задача — новый чат.

Формулировка: «Чат длинный, каждый ответ здесь дороже. Обновил капсулу — открой новый чат и напиши „капсула“».

## Конец рабочего блока — обновить капсулу

Файл памяти `/areas/kapsula.md`, не больше 2 КБ:
1. Главная задача — 1 строка.
2. Действующее решение — 2–3 строки.
3. Что сделано последним и где лежит — ссылки, без пересказа.
4. Открытые решения, которые ждут его «да».
5. Следующее действие — 1 строка.

Капсула **заменяется**, а не дописывается: старое уходит в журнал решений на странице «ЯКОРЬ» в Notion.

## Чего не делать

- Не перечитывать в новом чате созвоны, канал, большие файлы, старые страницы — выжимки уже есть.
- Не загружать «на всякий случай» оркестратор, все скиллы, все страницы.
- Не обещать, что длинный чат станет дешёвым. Дешёвым его делает только новый чат с капсулой.
