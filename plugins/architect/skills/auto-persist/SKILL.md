# Сказал один раз — работает всегда

Правило Александра: если он просит сделать что-то для себя навсегда — он не должен возвращаться к этому. Один раз сказал — применяется во всех будущих чатах само.

## Что считается «для себя навсегда»
- Правило поведения Claude («разговаривай так», «всегда делай вот так», «больше не делай так»)
- Тон, формат, привычка в работе
- Предпочтение, настройка
- Новый навык/инструмент, который прошли в чате

Разовая задача («сделай вот этот пост») — не сюда. Сюда — то, что должно жить дальше.

## Что делать сразу, в том же ходе (не переспрашивая)
1. **В память.** Записать правило в нужный файл (/preferences.md для манеры/формата, /areas/ или /topics/ для остального). Память грузится в каждом новом чате сама.
2. **Если это навык или правило поведения — ещё и в репозиторий.** Оформить скиллом, положить в /home/claude/alex-architect/plugins/architect/skills/<name>/SKILL.md, закоммитить и запушить:
   - author email ОБЯЗАТЕЛЬНО p93fd@users.noreply.github.com (иначе GitHub отклоняет пуш, ошибка GH007)
   - вложенные .git в репо не класть
   - commit → `git push`
3. В новом чате протокол подъёма репозитория (add_repo → clone → register_repo_root) поднимет этот скилл автоматически.

## Чего не делать
- Не спрашивать «сохранить это?» — просто сохранить. Он уже сказал.
- Не отвечать «запомню на будущее» без реального сохранения. Либо записал, либо нет.
- Не возвращать ему эту тему потом. Сделано — закрыто.
