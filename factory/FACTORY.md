# Завод контента Александра

Порядок работы для запуска по расписанию и по команде «прогони завод». Каждый запуск стартует с нуля: читает этот файл и папку state.

## Правила
- Ничего не публикуется без его «да» в группе «Одобрение контента».
- Тексты от его лица собирать из его голосовых и опор из памяти о речи. Скиллы: conversion-article, humanizer-ru, ai-tells. Факты и цифры не выдумывать.
- В конце любой связки диагностика. Статьи и посты ведут на его личный Телеграм.
- Ключ бота в репозиторий не класть. Он лежит в тексте задания по расписанию.
- Один запуск — одно сообщение-сводка в группу и отдельные сообщения на каждый черновик. Коротко.

## Цеха
1. Аналитик. Статистика Инстаграма через vidIQ: что набрало за 7 дней, какие темы и заходы. Плюс до трёх свежих новостей по теме. Итог: сводка в группу.
2. План. Из сводки и банка идей: темы на неделю, по одной строке. Файл state/plan.md.
3. Тексты. Черновик поста в Телеграм, текст карусели, планы рилсов. Только из его слов в state/ideas.md и расшифровок. Файлы в drafts/.
4. Карусели. Картинки слайдов, после одобрения текста.
5. Банк идей. Голосовые и сообщения из группы расшифровать и дописать в state/ideas.md дословно.
6. Рилсы. Монтаж присланного видео по скиллу монтажа.
7. Гайды. PDF под кодовое слово.

## Одобрение
Каждый черновик уходит в группу с номером: «Черновик 12. Пост в Телеграм». Он отвечает на сообщение: «да», «переделай: …» или «нет». Следующий запуск читает ответы: «да» публикует, «переделай» правит и присылает снова, «нет» убирает.

## Публикация
- Телеграм-канал: бот, после «да».
- Рилсы в Инстаграм: vidIQ, после «да».
- Карусели в Инстаграм и Тредс: через сервис публикаций, когда будет ключ. До этого готовые файлы приходят в группу, выкладывает сам.

## Память завода
- state/plan.md — темы недели.
- state/ideas.md — банк идей его словами.
- state/log.md — что отправлено, что одобрено, номер последнего прочитанного сообщения группы.

## Цепочка рилса (проверено 04.10.2026)
1. Вход. Видео до 20 МБ — прямо в группу. Тяжёлое, в полном качестве — в папку Google Диска «Завод — видео для монтажа» (id 1i3E5i90Re2jQeZUD8iB2zKojPH9KKfCZ, доступ по ссылке). Забирать: список через коннектор Диска, файл через gdown по id.
2. Расшифровка по словам: faster-whisper, модель large-v3-turbo, если медленно — medium. Итог words.json.
3. План монтажа plan.json. По умолчанию для него:
   - сильная фраза из середины ставится в начало (cold_open), дальше ролик целиком;
   - тёплый цвет (grade warm), скорость 1.06, звуки переходов (sfx);
   - субтитры по три слова, активное слово подпрыгивает и подсвечено;
   - 2–4 вставки по 2–3 секунды: свои (gen-insert sphere | network | particles) или сток под смысл фразы, без подписей авторов;
   - 1–3 текстовые плашки (titles): то, чего голос не говорит — цифра, название шага, итог. Не повторять сказанное;
   - призыв «напиши в директ» в кадр не ставить. Кодовое слово — в подписи под видео;
   - музыку не накладывать: он ставит звук в Инстаграме сам.
4. Рендер: python3 factory/montazh.py render plan.json. Минута ролика считается около 8 минут.
5. Проверка: открыть reel_check.jpg, посмотреть каждый кадр. Хук читается, субтитры не на лице, вставки на месте.
6. Показ: reel_tg.mp4 и текст подписи в группу, с номером черновика.
7. После «да»: reel.mp4 в ветку media репозитория → прямая ссылка raw.githubusercontent.com/p93fd/alex-architect/media/<файл> → vidiq_video_upload → vidiq_instagram_publish_reel с trialParams MANUAL, аккаунт alekskomlew. Ссылку на рилс прислать в группу. Ветку media после публикации очистить.
8. «Переделай: …» — править план, не начинать заново.

## Без видео
Пост в Телеграм, карусель, статья, гайд PDF собираются из голосовых в банке идей. Усиление поста: одна картинка-схема или плашка с главной фразой. Всё через одобрение.
